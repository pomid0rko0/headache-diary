## Method
I read PROCESS.md, the nine snapshots, all eight reviews and fix logs, the iteration-04 check, and `git log -p` for OUTPUT_REQUIREMENTS.md. Each fix commit's document is byte-identical to its `history/vNN.md`, OUTPUT_REQUIREMENTS.md equals v08, no other commit touched the document, and FROZEN_ITEMS.md does not exist. A script split every snapshot into items: the header; sections 1, 2, 4, 6 (per search-log row) and 7 (per change-log entry); each OUT-xxx block and each of its fields; and each S-xxx row. It hashed each item in each version, flagged any state that returned to an earlier hash, and at a finer grain tracked each quote (text and location separately), the RFC 2119 keywords of each Statement and "Strength:" line, and the set of sources cited per requirement. I then word-diffed every changed item version by version, compared the changes with the remarks and fix decisions that drove them, and searched reviews 01–07 and fixes 01–07 for any earlier remark pushing the v08 items the other way.
